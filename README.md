# Python-Exercises: Minha Jornada de Fundamentos 🚀

Bem-vindo ao meu repositório de exercícios de Python!

Este projeto é o meu campo de treinamento pessoal, onde eu resolvo problemas e fortaleço minha lógica de programação com os conceitos fundamentais da linguagem. Todos os exercícios aqui foram resolvidos "na unha", sem o auxílio de inteligência artificial, como forma de construir uma base de conhecimento sólida e duradoura.

## 🧠 Tópicos Abordados

Aqui você encontrará exercícios cobrindo as seguintes áreas essenciais do Python:

* 📁 **Estrutura de Decisão:** Lógica condicional com `if`, `elif` e `else` para criar programas que tomam decisões.
* 🔁 **Estrutura de Repetição:** Uso de laços `for` e `while` para automatizar tarefas e iterar sobre dados.
* 📝 **Exercícios com Strings:** Técnicas de manipulação, fatiamento e formatação de texto.
* ⛓️ **Exercícios com Listas:** Práticas com uma das estruturas de dados mais versáteis do Python, incluindo métodos e manipulação de coleções.
* 📦 **Exercícios com Funções:** Como organizar o código em blocos reutilizáveis, tornando os programas mais limpos e eficientes.

## Como Navegar

Cada pasta representa um tópico de estudo e contém os arquivos `.py` com os desafios e minhas respectivas soluções. Sinta-se à vontade para explorar!
